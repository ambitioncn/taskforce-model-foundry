# v0.2.0 — HF/PEFT runtime and evaluation reliability

This release adds tested single-GPU HF/PEFT execution, checkpoint resume,
EOS-terminated supervised targets, batched evaluation, and correct adapter
lineage reporting. Background OpenClaw evaluation now uses attempt-bound
reports and an independent systemd user worker where available, so a stale
report cannot be mistaken for a new result. Reports record the actual
evaluation device.

Verification before publication:

- TinyLlama 1.1B LoRA training, independent evaluation, gated export, and
  offline adapter reload were exercised on a single NVIDIA GB10.
- The repaired Gateway plugin completed a 1.1B background evaluation with
  4/4 prespecified technical gates passing.
- An eight-class public BANKING77 pilot reached 144/160 exact matches after
  tuning versus 0/160 with the base model. This is not a full 77-class
  benchmark or enterprise-data acceptance.
- Isolated tests exercised duplicate submissions, checkpoint recovery after
  SIGKILL, corrupted inputs, simulated ENOSPC, and consecutive jobs.

Limits: live Gateway restart survival, real host power loss and physical disk
exhaustion were not measured. The public pilot does not establish full business
readiness, and no private production data is included in this release.
