# v0.4.0 — harness-independent, bounded campaigns

Foundry's core operation contract is now independent of any agent harness.
OpenClaw and Hermes remain optional adapters to the same standalone package.

- Standalone `tmf campaign run/start/status/cancel` can advance predeclared
  candidates in a durable background worker with frozen model/data/gates,
  explicit trial/step/deadline budgets, replay, and cancellation.
- A bounded proposal mode creates new hyperparameter configurations inside an
  approved space. The `reflective` strategy records failed gate evidence,
  comparison, hypothesis and next action before contrasting, extrapolating or
  pivoting. It can choose non-neighboring points.
- Missing or inadequate gate evidence halts proposal search. Campaigns do not
  lower thresholds, invent datasets/models, auto-export or claim business
  acceptance. External-quality evidence remains project-owned.

Verification on the merged feature PR: GitHub CI passed 256 tests with 0
failures; 5 optional HF/PEFT tests were skipped because that runner does not
install the Python ML stack. The campaign/background targeted suite passed
14/14 locally. The release commit must pass its own CI and package smoke test.

Limits: built-in reflection is a bounded experiment heuristic, not an
unrestricted LLM research agent. Linux systemd user units are preferred for
background durability; direct-detached fallback is weaker. No power-loss,
business-quality or paused screenplay-RSI acceptance is claimed.
